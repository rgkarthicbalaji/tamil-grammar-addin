தமிழ் இலக்கணப் பிழை திருத்தி

Tamil Grammar Checker for Microsoft Word

Word-இல் தமிழ் எழுத்துப் பிழை, புணர்ச்சி (வல்லினம் மிகும் / மிகா), எழுவாய்–பயனிலை இயைபு, நடை ஆகியவற்றைச் சரிபார்க்கும் செருகுநிரல். It checks Tamil spelling, sandhi, subject–verb agreement and style, and offers one-click fixes. Your text never leaves your computer.

Word-இல் நிறுவுதல் · Install in Word

  1. மேலே உள்ள Download manifest பொத்தானை அழுத்திக் கோப்பைச் சேமிக்கவும். (If the file opens as text instead, right-click the button and choose Save link as.)
  2. Word-ஐத் திறக்கவும்: Word on the web (office.com) or Word for Microsoft 365.
  3. Insert → Add-ins → More Settings / My Add-ins → Upload My Add-in → choose the saved file → Upload.
  4. Home → Tamil Grammar பொத்தானை அழுத்தி, சரிபார் · Check அழுத்தவும்.

Underlines inside the document need Word with a Microsoft 365 subscription. On other versions the issues are listed in the side panel, with fix buttons.

சோதனை வாக்கியம் · Try this sentence

நான் அவனை கண்டேன். பறவைகள் பறந்தது. → அவனைக் கண்டேன், பறந்தன.

Rules follow இளங்கோ தமிழ் இலக்கணம் (1942) and மழவை மகாலிங்க ஐயர், தமிழ் இலக்கணம்.
